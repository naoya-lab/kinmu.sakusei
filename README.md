# 放射線取扱作業等手当（月次・1名）

文字情報付きの勤務表PDFから指定した職員1名の勤務区分を読み取り、元のExcel様式の「①」欄（H5:H35）に〇を記入します。氏名・職員番号・合計日数の計算式を保持します。

## 使い方
Python 3.10以上を用意して、`pip install -r requirements.txt` を実行します。次に：

```bash
python main.py "2026年10月勤務表（1007）.pdf" "放射線取扱作業等手当(R3.1以降).xlsx"
```

初回だけ対象職員の氏名を入力します。翌月以降はその月のPDFを指定します。結果は `放射線取扱手当_記入済.xlsx` と `判定確認.csv` に出力されます。

## 判定の注意点
赤字に加えて「週・休・年休・夏季・子看・服忌・代・欠・出張」を含む勤務区分を除外します。その他は仮に〇としますが、夜勤・研修・日勤などの実際の放射線取扱作業への従事は、勤務表だけでは保証できません。**提出前にCSVと実際の従事記録を照合してください。** PDFの構造が違う場合にはエラーで停止します。スキャンPDFには非対応です。

公開リポジトリに勤務表・元のExcel様式・出力Excel・判定表・local_config.jsonをコミットしないでください。ファイルは端末上だけで処理します。

## iPhone / Safari用 GitHub Pages版

`index.html` を追加しました。GitHub の Settings → Pages から main / (root) を選択し、公開設定を保存してください。公開URLは通常 https://naoya-lab.github.io/kinmu.sakusei/ です。

ブラウザで勤務表PDF（文字情報付き）と元の定型Excelを選び、対象者名を入力して「勤務日を解析」を押します。日別の丸印を確認・修正し「確認内容でExcelを作成」を押してください。PDF.jsとJSZipをCDNから取得しますが、勤務表やExcelファイルはサーバーへ送らずブラウザ内で処理します。Safariのダウンロード先は通常「ファイル」アプリです。

**注意：** これは初期実装です。iPhone実機での動作確認は未実施です。様式のセルを直接更新する方式で、合計欄には元のCOUNTIF数式が残ります。支給判定が正しいことを保証するものではありません。提出前にすべての○と計算結果を確認してください。
